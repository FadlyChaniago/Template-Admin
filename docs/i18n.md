# Terjemahan (ID / EN)

```js
K.t('nav.users')                                   // "Users" / "Pengguna"
K.t('table.showing', { from: 1, to: 10, total: 38 }) // interpolasi {from}
K.i18n.set('en')                                   // ganti bahasa (tersimpan)
K.i18n.lang                                        // 'id' | 'en'
```

## HTML statis

```html
<span data-i18n="shell.upgrade">Upgrade Plan</span>
<input data-i18n-placeholder="shell.search" placeholder="Cari…">
<button data-i18n-aria="shell.menu" aria-label="Buka menu">…</button>
<a data-i18n-title="shell.notifications" title="Notifikasi">…</a>
```

## Urutan fallback

`kamus bahasa aktif` → `kamus Indonesia` → `kunci itu sendiri`. Jadi kunci yang lupa diterjemahkan tampil sebagai `nav.products` — mudah terlihat saat QA.

## Apa yang diterjemahkan

Shell (sidebar, topbar, palette, pintasan), DataTable, modal/confirm/toast, status badge, halaman error, Dashboard, Users, dan General Settings. Halaman lain memakai Bahasa Indonesia sebagai teks sumber; terjemahkan bertahap dengan pola yang sama (template ini sengaja tidak menerjemahkan semua konten demo — itu biasanya berasal dari backend).

## Menambah bahasa

1. Buat `assets/js/i18n/ms.js`:
   ```js
   K.i18n.add('ms', { 'nav.users': 'Pengguna', /* … */ });
   ```
2. Muat setelah `en.js` di `index.html` (dan halaman auth/error bila perlu).
3. Tambah opsi di **Preferences → Localization**.

Saat bahasa berganti, event `k:locale` dipicu; shell dan halaman aktif dirender ulang otomatis.
